# Evan AI OS

A personal AI operating system for knowledge, skills, workflows, agents, prompts, evals, templates, projects, and inbox.

## Structure

- `knowledge/` — durable knowledge and mental models
- `skills/` — executable reusable capabilities
- `workflows/` — multi-step operating procedures
- `agents/` — role definitions and agent specs
- `prompts/` — reusable prompt assets
- `evals/` — evaluation standards
- `templates/` — repeatable document templates
- `projects/` — project briefs and working context
- `inbox/` — temporary capture before triage

## Operating principle

ChatGPT Memory is for personal context; this repository is for explicit, versioned, inspectable knowledge and decisions.

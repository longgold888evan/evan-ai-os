# Inbox

Temporary capture zone for ideas, links, notes, candidate knowledge, and drafts that have not yet passed the OS promotion gate.

The Inbox is **not durable truth**.

## Canonical flow

```text
conversation / file / project
        ↓
inbox candidate
        ↓
classify
        ↓
DRAFT
        ↓
validate with evals/knowledge_promotion_eval.md
        ↓
ACTIVE destination
```

Read:

- `workflows/memory_knowledge_promotion.md`
- `evals/knowledge_promotion_eval.md`
- `templates/knowledge_candidate.md`

## Possible destinations

```text
Durable knowledge
→ knowledge/<domain>/

Important durable choice
→ knowledge/decisions/

Repeated reusable method
→ skills/ or workflows/ after eval

Project-specific context
→ projects/<project>/

Not durable / failed validation
→ discard or leave transient
```

## Inbox discipline

Do not keep items forever merely because they were once interesting.

Each review should decide:

```text
PROMOTE
REVISE
MERGE
KEEP_DRAFT
ARCHIVE / DISCARD
```

Never place credentials or raw authentication material here.
